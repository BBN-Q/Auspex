# DataBrowser (read-only first slice)

The standalone dark-themed PySide6/pyqtgraph browser watches **multiple OS folders** for directly contained V2 `.auspex` run folders, and can also add individual `.auspex` runs. With the optional GUI dependencies installed (`python -m pip install -e './v2[gui]'`), run from the repository root:

```sh
python v2/utils/data_browser.py                              # Add folder… or File → Add single .auspex run…
python v2/utils/data_browser.py /lab/runs /other/runs run1.auspex
```

For a **manual visual demo**, run `python test/gen_test_data.py` to create deterministic synthetic run folders in `test/test_data/`, then `python v2/tests/data/visual_data_browser.py` to open the containing OS folder and three dataset tabs across two runs. The latter generates any missing demo folders automatically and opens the noisy three-Lorentzian trace first. The other synthetic experiment is a decaying, chirped Ramsey interference trace with beating and a late revival; a complex S21 trace exercises component selection. These are *not* laboratory measurements. The `.auspex` outputs are gitignored; rerun the generator to recreate them. Existing demo folders are never overwritten. The visual demo is intentionally not collected by unittest discovery.

The left tree shows **OS folder → `.auspex` run → group → dataset**, plus individually added runs as top-level entries. OS folder discovery is **one level only**, not recursive. Use **Add folder…** (or File → Add folder containing .auspex runs…) to watch a directory, and File → Add single .auspex run… for an individual run. The same run is shown only once if it is both watched and directly added. Double-click a supported dataset to open or focus its tab. Switching tabs highlights that dataset in the tree and updates the metadata pane; selecting an already open dataset in the tree focuses its tab. Selecting a closed or unplottable dataset shows its metadata without opening a new tab. Supported **plots** are only non-ragged, 1D numerical arrays. Multidimensional and ragged datasets remain selectable in the tree for metadata inspection, but are grayed out and labeled *plotting not yet supported*. The browser loads arrays only for opened 1D tabs, never just to populate the tree. Each tab plots actual stored numeric coordinates rather than a generated uniform grid; choose an X coordinate if the dataset has several coordinates indexed by its dimension. Complex data can be displayed as magnitude, real, imaginary, or phase. These are display modes; data files are not modified. There is no slicing, fitting, data export, processing or instrument access.

The right pane shows nested JSON for the selected run's `metadata.json` (if present), the manifest snapshot, and the selected dataset's **self-describing `.dat` header**. Coordinate arrays themselves live in the `.dat` binary section and are not expanded into thousands of JSON rows. The **Refresh** button or File → **Refresh all folders and datasets** (`Ctrl+R`) rescans every watched OS folder for newly created/removed direct `.auspex` children, and reloads all run manifests and small dataset headers. Open plot tabs remain unchanged for runs that still exist; tabs for runs that disappeared from watched folders close. Closing a tab drops its in-memory dataset and plot references; the dataset remains available in the tree. Right-click a **`.auspex` run** and choose **Close all datasets** to close only that run's tabs without removing it from the tree. Right-click a watched **OS folder** and choose **Remove folder** (or use File → Remove selected folder/run) to stop watching it and close its tabs. Directly added runs can be removed separately. Neither action deletes files. If a run was both directly added and watched, removing the OS folder still closes its tabs, but the direct run remains available to reopen.

This viewer only lists datasets in a valid V2 manifest; it does not inspect unpublished or orphaned files, automatically refresh, follow a run, read V1/old-V2 format 1, or plot ragged/dependent/multidimensional arrays. Use `AuspexStore.read_file()` for manual recovery from an individual `.dat` if the manifest is lost. Readers load plotted datasets fully into memory, so avoid opening many large tabs. Run metadata may contain sensitive lab settings; the GUI does not redact or upload it.
